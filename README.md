# iOptic — إصدارات تطبيق الهاتف والتاب (Android)

هذا المستودع يحمل بيان التحديث `version.json` وملفات APK لتطبيق **iOptic للهاتف**.
مستودع النسخة المكتبية منفصل: `ioptic-releases`.

- `version.json` على الفرع الرئيسي: `{"version","apkUrl","notes","size"}`
- كل إصدار وسمه `v<version>` وملفه `ioptic-<version>.apk` كأصل في Release.

التطبيق يفحص هذا البيان عند كل فتح ويعرض «تحديث جديد» بأزرار: تجاهل الإصدار · لاحقاً · تنزيل.
